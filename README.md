# Splash Screen animada en React Native

Este proyecto es un ejemplo de cómo animar tu Splash Screen en React Native utilizando lottiefiles

## Cómo empezar

1. Instalar dependencias

   ```bash
   pnpm install
   ```

2. Iniciar App

   ```bash
   pnpm ios
   ```
